# Gold Star · site demonstração

Site de demonstração para a Gold Star Consultoria e Investimento (consórcio e patrimônio, sudoeste goiano).

- **Abertura animada:** aperto de mão em dourado que vira o logo e encolhe até a barra do topo.
- **Simulador:** consórcio x financiamento, com gráfico e envio da simulação pelo WhatsApp.
- **Mapa do patrimônio:** o visitante arrasta objetivos para os próximos 10 anos e recebe o plano somado.
- Entregas, avaliações (exemplos), dúvidas e vídeo do consultor.

Site estático: basta abrir `index.html` ou publicar a pasta no GitHub Pages.

As taxas do simulador são de exemplo e ficam no bloco `BENS` em `js/app.js`.
`js/intro-dados.js` é gerado a partir do logo dourado e de `animacao/maos-douradas.json`.

Animação das mãos: "Handshake Loop", de Brian Karungani (LottieFiles, Lottie Simple License), recolorida em dourado.
